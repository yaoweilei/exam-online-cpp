# 学员学习体验检查

检查范围：学员工作台、今日复习、专项练习、复习资料、学习报告。产品目标为语言学习；用户所说的“只有真题试卷”按当前内容形态理解，并非断言库内只有一份试卷。

## 本次界面调整

今日复习、专项练习、学习报告、错题本、生词本、到期复习、每日一练、推荐复习和学习目标在已打开的角色工作台右侧显示。保留筛选、数据请求和原有操作。切换页面无需关闭弹窗；确认删除等操作仍使用确认对话框。

## 当前问题

| 观察 | 对学习的影响 | 建议 |
| --- | --- | --- |
| 今日复习聚合到期题、错题和每日题；优先到期题，再错题，再每日题 | 主要安排重复做题，没有明确的新知识学习任务 | 分为学习新内容、练习应用、复习旧内容，并允许学生设置每日时间 |
| 今日复习在待办数为零时直接显示已完成；完成数只来自每日练习 | 新用户可能被告知已经完成学习；进度没有统一口径 | 区分尚未开始、暂无任务、真正完成；按同一个任务集合记录完成状态 |
| 专项练习按考试、等级、考点聚合题目和正确率 | 适合备考，但知识讲解和练习之间没有明确的先后路径 | 每个知识点提供讲解、例句、少量练习、错因回顾和复习入口 |
| 复习资料包含错题、收藏题和生词本 | 是个人收集箱，不能承担新学生的系统学习入口 | 增加按等级组织的词汇和语法内容；个人收集继续独立保留 |
| 学习报告主要显示答题数、正确率、错题、复习和连续天数 | 学生知道做了多少，却不清楚接下来应该学什么；重复做熟题也可能提高正确率 | 区分首次与重复作答，按技能显示样本量、薄弱点和下一步任务；避免直接等同语言能力 |
| 当前检查到的学习入口围绕试卷和题目 | 真题可以检验学习，但独立承担入门教学不足 | 优先把真题材料加工成精读、精听及词汇语法学习单元 |

## 建议的最小学习闭环

先选择等级和目标 → 学一个知识点或一段材料 → 完成少量练习 → 看解析、标记错因 → 加入复习 → 在新题或新语境中验证。

首阶段不必增加大量栏目：把现有真题的一篇阅读或一段听力做成完整学习单元。阅读提供分段理解、词语及语法解释；听力提供逐句播放、听写、原文对照。原卷考试模式继续用于阶段检测。

后续再补口语跟读、表达和写作反馈，并明确反馈标准。以上为产品建议，本次未新增这些课程内容或能力评估功能。
