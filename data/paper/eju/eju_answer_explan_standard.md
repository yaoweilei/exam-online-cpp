# EJU 答案解析统一标准

## 0. 执行版摘要

生成 EJU 答案解析时，优先按本节执行；后文是细则和验收标准。

### 0.1 先判题区

- `記述`：作文题。重点讲审题、立场、理由、结构、写作提醒。
- `読解`：阅读题。重点讲原文证据、题干问法、正确项对应、误选陷阱。
- `読聴解`：读听解。必须同时讲题册图表/材料和音频条件，不能只讲一边。
- `聴解`：听解。重点讲音频信息流、转折/定案句、误听来源。

### 0.2 每题必须讲清五件事

1. 这题问什么。
2. 证据在哪里。
3. 为什么正确答案成立。
4. 其他选项为什么不成立。
5. 下次遇到同类题怎么做。

### 0.3 字段分工

- `explanation`：只负责本题判断链，讲清“为什么这样选”。
- `explanation_expand`：只负责复盘与迁移，讲清“下次怎么稳定做对”。

不得把 `explanation_expand` 写成 `explanation` 的重复版。

### 0.4 题区重点

- `記述`：若有两个主题，主题 1 放 `explanation`，主题 2 放 `explanation_expand`。
- `読解`：必须说明关键句、关键段或文章推进关系，不得只翻译。
- `読聴解`：必须说明图表先看什么、音频新增什么条件、答案如何同时满足两边。
- `聴解`：必须说明哪一句或哪一组句子真正决定答案，前面信息为什么不是最终答案。

### 0.5 禁止模板腔

最终解析不得出现：

- `共同限定`
- `有效信息指向`
- `该项与定位信息不一致`
- `解题时先确认问题问的是`
- `对象、动作和结论`
- `注意定位`
- `认真听转折`
- `结合上下文`
- `其他选项均不符合`

如果要表达类似意思，必须落到本题具体证据、具体选项和具体错因。

### 0.6 缺题处理

原题未刊载或材料不足时，不得伪造解析。只写缺题说明，并建议自学者跳过。

## 1. 文档用途

本文件是 EJU 日本语试卷答案解析的生成与验收标准。

目标不是统一一个好看的标题格式，而是保证每一道题的解析达到可直接给自学者使用的教师讲解水平。

生成或改写 EJU 解析时，必须先完成三件事：

1. 判定题区：記述、読解、読聴解、聴解。
2. 找准证据：原文、图表、题干、选项、音频脚本、最终提问。
3. 写出判断链：为什么正确项成立，为什么其他项不成立，下次怎么做。

格式可以在题型内保持适度灵活，但内容质量不得降低。

## 2. 总原则

### 2.1 优先级

1. 判断正确，证据落准。
2. 学生能据此复盘并迁移到下一题。
3. 行文像人类老师写给自学者的正式讲解。
4. `explanation` 与 `explanation_expand` 分工清楚。
5. 标题、口吻、长度大体稳定。

标题统一只是最低要求。标题合规但内容空泛、机械、错位，仍然视为不合格。

### 2.2 每题必须回答的四个问题

每一道有效题都必须回答：

1. 这题真正问什么。
2. 正确答案为什么成立。
3. 干扰项为什么不成立。
4. 下次遇到同类题应该按什么动作处理。

对 EJU 而言，“答案为什么成立”不能只写“原文对应”“音频提到”“图中可见”。必须说明对应关系如何成立。

### 2.3 字段职责

所有题默认使用：

- `explanation`
- `explanation_expand`

`explanation` 负责讲清本题的作答判断链：

- 题目问什么。
- 证据在哪里。
- 为什么正确答案最合适。
- 其他选项错在哪里。

`explanation_expand` 负责服务自学复盘和迁移：

- 这类题下次怎么听、怎么读、怎么定位。
- 题目里有哪些常见陷阱。
- 哪些表达、逻辑、图表关系值得复习。
- 必要时给出简洁翻译、表达补充或作文思路。

不得把 `explanation_expand` 写成 `explanation` 的换句话重复。

### 2.4 内容质量硬标准

一题达标必须同时满足：

1. 正确答案与 `correct_answer` / `answer` 一致。
2. 证据句、图表点、音频定位句没有落错。
3. 误选项分析逐项对应实际选项。
4. 解析能解释“为什么会被干扰项骗到”。
5. 方法提醒能转化为具体动作。
6. 中文自然、稳定、像正式教辅，不像脚本输出。

以下情况直接判为不合格：

- 正确项选对了，但理由说偏了。
- 用翻译代替分析。
- 只讲正确项，不讲干扰项。
- 干扰项分析全是同一句模板。
- 只写“对象、动作、原因、结果”这类抽象分类，却不落到本题材料。
- `explanation_expand` 大段重复主解析。
- 解析里出现明显机器腔、审稿腔、流程腔。

### 2.5 禁用信号

以下表达在最终成品中默认禁用：

- `音频的有效信息指向`
- `这些信息共同限定了对象、动作和结论`
- `该项与定位信息不一致`
- `解题时先确认问题问的是`
- `本题的关键是把问题中的要求和音频里的有效信息对应起来`
- `正确答案是...这些条件共同指向...`
- `只要抓关键词即可`
- `可直接排除`
- `其他选项均不符合`
- `待补充`
- `略`
- `AI`
- `模板`
- `生成`
- `pass`
- `fail`
- `trace`
- `select`
- `正确答案：`

这些话不是绝对不能表达其含义，而是不能以这种机械句式进入成品。必须改写成本题专属的证据分析。

### 2.6 缺题与未刊载题

若原题因出版原因未刊载，或当前数据缺少题干、选项、音频脚本、图表材料，不能伪造解析。

应写成缺题说明：

- 说明原始资料未刊载或材料不足。
- 明确不能生成可靠答案解析。
- 建议自学者跳过，不根据残缺信息猜答案。

不得为了凑完整度编造题意、证据或误选分析。

## 3. EJU 题区标准

## 3.1 記述

EJU 記述不是选择题，解析重点不是“正确答案”，而是“如何审题、立论、组织文章”。

### 3.1A 内容任务

必须讲清：

1. 题目要求写什么。
2. 两个主题或两个立场分别该如何展开。
3. 可用观点、理由、例子、让步句。
4. 400-500 字文章的结构安排。
5. 哪些写法容易跑题或过于空泛。

### 3.1B 双主题处理

若作文题给出两个主题：

- `explanation`：处理主题 1。
- `explanation_expand`：处理主题 2。

每个主题至少包含：

- 审题说明。
- 可选立场。
- 两个以上可展开理由。
- 一个简洁结构建议。
- 自学者写作提醒。

不得只给中文大意，不给写作路径。

### 3.1C 写作解析禁忌

不得：

- 把作文解析写成唯一标准答案。
- 只给中文观点，不说明日文作文如何组织。
- 给过度华丽、难以模仿的范文思路。
- 使用空泛表达，如“结合自身经历展开即可”。

合格的作文解析应让学生知道：下一步可以怎样开头、怎样分段、怎样举例、怎样收束。

## 3.2 読解

読解解析必须基于原文与选项，不得只复述中文翻译。

### 3.2A explanation 必须包含

1. 文章或段落的核心内容。
2. 题目问的是主旨、理由、细节、指代、段落作用、信息对应还是态度变化。
3. 关键句或关键段在哪里。
4. 正确项与关键句如何对应。
5. 每个误选项具体错在哪里。

### 3.2B explanation_expand 必须补充

1. 文章推进逻辑。
2. 本题陷阱来源。
3. 同类题的定位流程。
4. 必要的关键表达或内容翻译。

### 3.2C 読解硬要求

- 主旨题必须说明全文如何推进到结论。
- 理由题必须说明因果关系，不得只摘一句。
- 指代题必须说明指代对象如何由前后文确定。
- 信息对应题必须逐项核对条件。
- 态度题必须说明态度变化或评价词。

误选项常见错因必须写实：

- 张冠李戴。
- 扩大范围。
- 缩小范围。
- 把例子当主旨。
- 把前文铺垫当结论。
- 忽略转折后的真正观点。
- 把相似词当同义。

## 3.3 読聴解

読聴解是 EJU 的重点题型，不能按普通听力或普通阅读处理。

### 3.3A 核心原则

读听解必须同时处理：

1. 题册材料：图、表、选项、说明文字。
2. 音频信息：定义、条件、比较、结果、最后提问。

正确答案必须同时满足题册材料与音频条件。只满足其中一边，不得判为正确。

### 3.3B explanation 必须包含

1. 题册材料在区分什么。
2. 音频新增了什么条件。
3. 最后问题要求把哪个条件落到图表或选项上。
4. 正确项如何同时满足图表信息与音频信息。
5. 干扰项缺了哪个条件，或把哪个条件对应错了。

### 3.3C explanation_expand 必须补充

1. 听前如何先看图。
2. 听中如何记录条件。
3. 听后如何排除只符合局部信息的选项。
4. 必要时说明图表轴、分类、箭头、顺序、数值变化。

### 3.3D 読聴解禁忌

不得：

- 只写“把音频和图表对应起来”而不说明怎么对应。
- 只摘音频句，不讲图表条件。
- 只看图片，不讲音频最终提问。
- 对所有误选项都写同一句“没有同时满足条件”。
- 把读听解写成普通听力“最终决定题”。

合格的读听解解析应让学生能复原：

1. 图上先看哪里。
2. 音频里哪一句给条件。
3. 为什么答案落到某个图形、编号、类别或曲线。
4. 其他选项具体差在哪个条件。

## 3.4 聴解

聴解解析必须围绕音频信息流，不得只罗列定位句。

### 3.4A explanation 必须包含

1. 题目问什么：原因、做法、建议、结论、特点、问题点、下一步行动、实验结果等。
2. 音频如何推进：背景、举例、转折、修正、结论。
3. 决定答案的句子是哪一句或哪一组句子。
4. 为什么这句才是答案，而不是前面提到的其他信息。
5. 误选项对应了哪类误听：前文铺垫、被否定方案、局部信息、对方意见、顺序错位等。

### 3.4B explanation_expand 必须补充

1. 复听流程。
2. 同类题听法。
3. 关键表达或转折表达。
4. 必要时给出精简原文与中文对照，但不得代替分析。

### 3.4C 聴解硬要求

不同听解题必须抓不同信息流：

- 人物对话：谁最后决定，决定前哪些方案被否定。
- 讲义说明：定义、分类、例子、结论之间的关系。
- 原因题：真正原因与背景原因的区别。
- 建议题：建议内容与效果说明的区别。
- 实验题：实验条件、实验结果、结论三者不能混。
- 问题点题：优点铺垫与问题点转折不能混。
- 下一步行动题：马上做什么与之后做什么不能混。

不得只写“最后一句是关键”。必须说明最后一句为什么改变或确认了前面的信息。

## 5. 人类教师感标准

“像人讲的感觉”不是口语化聊天，而是解释要有教学判断。

合格文本应做到：

1. 先帮学生看懂题目任务。
2. 再指出真正决定答案的证据。
3. 再解释干扰项为什么有迷惑性。
4. 最后给出下次可执行的动作。

不合格文本常见表现：

- 看似很长，但都是定位句堆砌。
- 每题都用同一套句子，只替换答案号。
- 错项解释没有对应选项内容。
- 只说“关键词”“定位”“结合上下文”，没有具体动作。
- 说“自学复盘”，但没有告诉学生怎么复听或怎么重读。

### 5.1 行文口吻

允许有教师讲解感，但必须保持正式、克制、可入库：

- 可以说“这题容易错在...”
- 可以说“听到这里不要急着选...”
- 可以说“这句话才把答案收住...”
- 不写“很简单”“一眼看出”“你只要...”这类轻率表达。
- 不写过度聊天式语气。

### 5.2 可执行提醒

提醒必须是动作，不是口号。

不合格：

- 注意定位。
- 认真听转折。
- 结合上下文。
- 不要只看关键词。

合格：

- 先圈出题干问的是“原因”还是“结果”，再回到转折后的结论句。
- 读听解先看图表轴和分类名，听音频时只记录新增条件。
- 听解遇到两个方案时，记录每个方案后面的否定、保留或最终采纳。
- 阅读理由题先找评价句，再找前一句或后一句的因果解释。

## 6. 机械复核标准

机械复核必须扫最终 JSON 中的 `explanation` 与 `explanation_expand`，不得只扫日志或生成说明。

最低复核项：

1. JSON 可解析。
2. 有效题必须存在 `explanation` 与 `explanation_expand`。
3. 正确答案题不得保留缺题说明。
4. 缺题不得伪造答案分析。
5. 禁用信号不得残留。
6. 旧生成标记不得残留。
7. 标题体系不得混乱。
8. `explanation_expand` 不得为空。

建议命中检查：

- `共同限定`
- `定位信息`
- `有效信息指向`
- `对象、动作和结论`
- `解题时先确认`
- `模板`
- `生成`
- `待补充`
- `正确答案：`
- `可直接排除`
- `其他选项均不符合`

命中不一定全部错误，但必须逐条人工确认，不能直接宣称达标。

## 7. 人工审查标准

人工审查不是读一遍看是否顺眼。每题必须按以下顺序判断：

1. 不看解析，先根据题干、原文、图表、音频脚本独立判断答案依据。
2. 再看 `explanation` 是否把这个依据讲清。
3. 再看误选项分析是否逐项成立。
4. 再看 `explanation_expand` 是否提供了迁移价值。
5. 最后检查口吻、标题、残留信号。

六项硬标准：

1. 判断是否正确。
2. 证据是否落准。
3. 误选分析是否逐项成立。
4. 方法提醒是否可执行。
5. 中文是否自然、稳定、像正式教辅。
6. 补充层是否真正补充。

只要有一项不成立，该题不得判为完成。

---

## 8. 生成流程

每次生成或重写 EJU 解析按以下顺序执行：

1. 读取题区、题干、选项、原文、音频脚本、图表材料。
2. 独立判断正确答案依据。
3. 写 `explanation`，先讲本题判断链。
4. 写 `explanation_expand`，再讲复盘与迁移。
5. 逐项检查干扰项是否真正对应。
6. 清理模板腔、流程腔、生成痕迹。
7. 对最终 JSON 做机械复核。
8. 抽样做人工审查，不用抽样结论替代全量验收。

---

## 9. 当前有效结论

EJU 解析的最终目标是：

- 記述：能指导学生审题、立论、组织 400-500 字文章。
- 読解：能讲清原文证据、选项陷阱和阅读定位方法。
- 読聴解：能讲清题册材料与音频条件如何合并判断。
- 聴解：能讲清音频信息流、转折/定案句和误听来源。

以后若升级模板，只能整批升级，不得单卷混用多个质量口径。
