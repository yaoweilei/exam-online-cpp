# EJU Paper Layout

Root-level JSON files such as `2010_01.json` are the exam entries loaded by the app.
The `reading/` directory is an intermediate source for section 2 (`読解問題`) and is not indexed as a standalone exam.
The `full/` directory is a legacy/sample generation output and is not indexed as a standalone exam.
