# 统一头像账号菜单

2026-11-02。

学习／答题页面的头像和各角色工作台的头像，现使用同一个账号菜单组件、渲染函数和操作处理。原来的大面板及工作台内重复生成的菜单已退出运行路径。

- 菜单统一为紧凑下拉，账号摘要、身份、资料安全、学员权益、切换与退出分组展示。
- 身份列表默认折叠，选项只来自当前账号已有角色；单身份不显示角色切换。学员身份保留套餐、优惠和帮助入口。
- 学习页面额外提供“进入当前工作台”；工作台内省略这一项。
- 点击头像只挂载菜单，不重新渲染业务页面。后台数据刷新替换页头时，菜单的展开状态和焦点会保留。
- 个人资料、安全统一在工作台打开；从学习页面打开时返回原学习页面，从业务页打开则沿工作台历史返回。修正机构角色被业务详情返回逻辑截获的问题。
- 切换身份继续通过原有权限校验，切换账号和退出清理旧菜单；没有更改服务端权限、角色或业务数据。
- 菜单支持点击外部关闭、Escape 关闭并回到触发头像、上下方向键导航，以及窄屏边界和最大高度约束。隔离旧工作台样式的影响。
