## 结论与顺序

当前问题集中在**机构端的旧版组合页面**和**二级详情/编辑状态**。用户管理列表、平台机构的教职人员列表、交易列表等已经较统一，不需要全部推倒重做。

确认整理出 **29 项**：**3 项优先处理的窄屏可用性问题、21 项布局/信息层级问题、5 项样式与文案统一项**。这些是不同的整改项，共用组件的问题只计一次，不按截图数量重复计算。

建议按下面的顺序修改：

1. 先处理看板溢出、质检路径裁切、课程表格操作藏在右侧这 3 项。
2. 整理机构端：概况只展示一次，成员/权限/课程/账单各自保留一层主容器。
3. 统一筛选、分页、表单与详情组件，减少各页面分别写样式。
4. 整理交易详情、老师批改、学员今日学习等高频任务。
5. 最后统一账号、帮助、登录与音频等剩余样式。

优先级含义：**P1** 是手机上已有信息裁切、横向撑宽或关键操作不在初始可视区；**P2** 是可以操作，但层级、密度和阅读顺序明显需要调整；**P3** 是统一和打磨。这里没有把卡片嵌套的自动检测数字直接当作缺陷，下面各项均结合截图与结构人工复核。

## P1：优先解决手机可用性

### M01 · 机构看板展开后，长标题撑出内容区

- 位置：机构管理员 → 机构看板 → 展开「学习概况与机构能力」；学习组平均分趋势、课时账户等列表。
- 现象：390px 内容区横向溢出约 **116px**，360px 约 **146px**。长「学习组名＋作业名」单行不换行，超出卡片和右边界；默认折叠时看不出问题。
- 证据：[展开后中段截图](screenshots/org-dashboard-390-middle-4.png)、[DOM 定位](org-dashboard-diagnosis.json)。主要是 `.pc-info-row > span`，不是允许横向滚动的表格。
- 调整：长标题允许换行；行内使用 `min-width:0`；名称与结果分为上下两段。去掉「外层概况 → 内层卡片 → 信息行」不必要的表面。
- 验收：360/390/540px 下长中文名和长账号均不撑宽内容区，结果数字完整。

### M02 · 内容质检详情的路径被截断

- 位置：超级管理员 → 内容工作流 → 质检详情；平台内容管理员的发布工作流复用相同区域。
- 现象：`/exam_info/sections/.../passages/...` 等路径在灰色诊断框内横向延伸，右侧内容看不全；390px 内容区溢出约 4px，360px 约 34px。
- 证据：[360px 质检详情](screenshots/platform-content-record-360-top.png)。
- 调整：错误说明优先展示中文，路径独立一行并允许任意位置换行；原始诊断内容折叠并可复制。不要只用 `overflow:hidden` 隐藏问题。
- 验收：每条阻断原因和完整定位路径均可读、可复制，检查/审核按钮不受影响。

### M03 · 课程模板/课时账户表格的主要操作藏在右侧

- 位置：机构管理员 → 课程包、课时管理。
- 现象：表格宽度约 650px，390px 下「查看／分配」等操作位于约 x=540px 以后，需要先横向滚动才能找到。滚动限制在表格内，没有撑宽整页，但手机任务入口不明显。
- 证据：[课程包默认列表](screenshots/orgAdmin-openRoleContent_org-course-packages-390-top.png)、[课时管理默认列表](screenshots/orgAdmin-openRoleContent_org-course-accounts-390-top.png)。
- 调整：手机改为两行记录：第一行名称与状态，第二行课时余额与操作；次要编号放展开详情。表格仅保留给桌面或显式「表格视图」。
- 验收：不横向滑动就能看到记录名称、剩余课时、状态和主要操作。

## 后续改动的统一规则

1. 一个业务区只保留一层完整白色容器；内部靠标题、留白和内缩细线分组。输入框、状态标签和真正的弹层不计入「多套一层卡」。
2. 手机列表默认两行；名称可换行，金额/状态/箭头有固定位置。长账号、长中文名称均要检查。
3. 搜索框外置，与列表边界对齐；筛选面板收纳条件、排序、顺序和每页数量；分页只负责翻页。
4. 表单基础字段优先，可选的技术参数折叠。新建、批改、结算等不同任务应有明确进入和退出，不在长列表中无限展开。
5. 默认空状态、少量数据、长名称、多成员、多页及展开态都要检查；仅默认折叠状态正常不能算通过。
6. 浮动搜索和底部按钮应预留滚动空间。不能简单用 `overflow:hidden` 把超宽信息裁掉，也不能用统一固定高度制造留白。
