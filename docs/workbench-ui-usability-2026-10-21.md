# 工作台易用性第一轮调整（2026-10-21）

沿用学员端的白底、橙色选中态、字体、圆角、内容对齐和 240px 侧栏宽度；不增加新的概览卡片或筛选层级。

## 本轮调整

- 所有管理角色的侧栏压缩分组间距和子菜单缩进；切换页面时默认展开当前分组，手动打开另一分组会收起其余分组。当前页面的橙色选中态在鼠标悬停时仍保留。
- 用户管理去掉搜索区外围的大卡片，采用搜索框、搜索、清除的紧凑工具栏，支持回车搜索。
- 用户列表采用账号/姓名、角色、状态、最近活跃、查看操作的表格；重复的账号和姓名只显示一次。默认按注册时间倒序展示，搜索时按匹配程度排序。
- 分页位于结果底部，保留每页数量选择；仅一页时隐藏跳页控件。手机端保留账号、角色、状态和查看入口，最近活跃可进入详情查看。
- 加载只显示列表占位行；空结果提供清除搜索；失败显示原因和重试按钮，并保留关键词。旧请求不会覆盖后发搜索结果。
- 用户详情主标题显示具体姓名，返回列表后保留关键词、页码和每页数量。
- 用户页新增仅超级管理员可调用的分页接口 `/api/v1/admin/users`，替代按七种角色全量加载后再在浏览器分页。仅丰富本页用户资料；搜索姓名通过现有 SQLite 搜索索引读取，搜索总数不再受原有 50 条候选上限限制。
- 窄屏审计日志限制表格滚动区域，防止表格最小宽度把整个页面撑宽。
- 管理列表分页的文字、下拉菜单和翻页按钮采用主题配色，深色模式下不再残留浅底和深色文字。

## 验证

- 前端 TypeScript 构建、后端 MinSizeRel 构建及 smoke tests 通过。
- 原有角色权限、机构授权、内容发布回滚、教师作业及学员进度流程回归通过。
- 新增真实接口测试覆盖 55 个匹配账号的完整分页、超出末页处理、姓名索引搜索、匿名和普通账号拒绝访问。
- 新增 UI 测试覆盖加载、分页、清空、空结果、失败重试、详情返回、搜索响应乱序、侧栏展开、手机端及深色主题。
- 共覆盖 39 项不同回归用例；针对最终样式补验 6 项用户页、全角色页面宽度和工作台概览测试。
- 深色模式分页补验文字对比度不低于 4.5:1，截图等待主题切换完成后再检查。
- 测试在 `8083` 隔离数据运行，产物位于 `tmp/ui-usability-20261021/`；没有将测试账号及进度覆盖到原有用户数据。
- 验证后的版本已更新到本地 `8080` 服务；健康和就绪检查通过，前端版本为 `20261021-workbench-usability-v1`，隔离服务已关闭。

本轮重点为公共导航和用户管理；其他角色的业务列表继续沿用现有组件，未宣称全部页面已重做。
