# 工作台菜单归并（2026-10-21）

移除“分类下面只有一个入口”的展开层级。管理端侧栏直接进入业务分区，分区内的相关功能通过内容顶部的导航切换；单项功能不显示多余的分区或页内导航。学员端继续沿用既有学习菜单。

## 平台管理

| 侧栏入口 | 页面内功能 |
| --- | --- |
| 总览 | 平台总览 |
| 用户与权限 | 用户管理、角色权限 |
| 机构管理 | 直接进入机构管理 |
| 内容管理 | 内容工作流、反馈处理 |
| 交易管理 | 订单与支付、价格与套餐 |
| 系统设置 | 功能开关、审计日志 |

## 其他管理角色

| 角色 | 侧栏入口 |
| --- | --- |
| 教师 | 总览、学员管理、教学任务、备课、消息中心 |
| 教学管理员 | 总览、学员运营、教务支持、消息中心 |
| 机构管理员 | 总览、成员与权限、教学运营、机构管理、消息中心 |
