# 全角色公共消息入口

## 界面与流程

- 学员、教师、教学管理员、机构管理员、机构内容管理员、内容管理员及超级管理员共用顶栏铃铛，位于头像左侧。
- 角标显示账号未读数量，零条隐藏，超过 99 显示 `99+`；支持 320px 窄屏及深浅主题。
- 首页业务区域、角色侧栏和头像菜单不再重复提供消息入口。
- 消息页使用“全部 / 未读”，保留来源、时间、正文及相关作业入口。系统消息按服务器筛选并分页加载，未读不局限于前 20 条。
- 打开消息保留当前角色及业务返回路径。直接从练习页打开时，返回继续显示原练习。
- 无需选择机构也可查看消息。切换账号、退出登录及请求过期时不会混入前一账号的通知。
- 深色模式调整消息行、未读背景、来源说明和筛选按钮的颜色；窄屏工具条优先同行排列。

## 已读记录

- 系统及续费通知沿用原有服务端已读接口。
- 作业提醒及批改反馈的已读记录保存至账号的 SQLite `message_reads` 集合，身份切换、刷新及其他设备读取共享记录。
- 新增 `GET /api/v1/me/message-reads` 和 `POST /api/v1/me/message-reads`。使用当前登录会话确定账号，写入采用合并并保留首次已读时间；单次限制 200 个标识。
- 单条或全部已读成功后更新列表和角标；失败保留未读并提示重试。合并操作部分成功时重新获取实际状态。
- 平台管理员的学员预览不收取其他学员的教学提醒。

## 验证与运行

- 前端 TypeScript、后端 MinSizeRel 构建及 smoke 可执行程序通过。新增后端持久化、幂等及账号隔离检查在发布构建中同样执行。
- 新增 5 项浏览器测试通过：七身份与三个宽度、业务返回、分页及未读查询、99+、已读失败重试、教学记录刷新持久化、练习页入口、游客隐藏、接口会话隔离、并发合并及输入校验。
- 既有 29 项工作台回归通过，覆盖角色首页、机构权限、教师作业与备课、主题、全部页面宽度、用户/机构/交易列表和菜单。统计增量用例首次与另一测试进程的账号创建重叠，单独重跑通过；本轮共 34 项不同浏览器用例验证通过。
