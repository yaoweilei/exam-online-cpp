# 各管理角色首页：学员风格与完整入口

## 范围

本轮将超级管理员、教师、教学管理员、机构管理员、机构内容管理员及内容管理员的首页，统一为紧凑的单列业务首页。学员页面保持原有结构。

## 首页入口

- 大块统计卡改为一条概况，待办与功能导航分开。
- 首页从现有菜单及当前角色的可见功能生成完整入口，不再只提供少量快捷操作。
- 多功能分类在首页内展开，同一时间打开一个分类；再次返回首页保留展开状态。单项功能直接进入，不增加分类层级。
- 非平台管理角色提供固定消息入口。账号资料、安全及身份切换保留在头像菜单。
- 窄屏默认收起侧栏时，全部业务页面仍可通过首页进入及返回。桌面两列分类，手机自动一列。

## 按角色调整

- **教师**：将最近课程单独突出，优先显示正在进行的课，其次显示未来 7 天内最近一节；已取消、已完成、缺席课程不计入。待批改和未提交独立呈现，课程不再算待办。
- **教学管理员**：概况保留学员范围及近期排课；待办只呈现催交和续费风险，避免再用包含两者的“异常提醒”重复计数。“异常提醒”等功能仍可从首页分类进入。
- **机构管理员**：成员、席位、学习组及课程包压缩为概况，首页补全成员权限、教学运营、机构设置、账单和日志入口。不限席位时不误报席位不足。
- **机构内容管理员**：直接展示课程包列表，支持首页搜索、每页 20 个、新建及编辑，复用原有校验和保存接口。更新保留记录 ID、状态和有效期；本地日期输入转换为 ISO 时间，未修改的有效期保留原值。保存失败保留输入，可重试；成功后定位已保存的课程包。停用课程不再一律计作异常或过期。
- **内容管理员**：概况改为内容总数和已发布；待完成工作流与待发布互不重叠。点击待办直接进入对应状态筛选，切换筛选清空原批量选择。三个业务功能直接展示。
- **超级管理员**：共享紧凑概况和完整分类入口，覆盖侧栏全部业务功能。

另外修复窄屏头像菜单的旧定位问题：固定定位配合百分比偏移可能将菜单放到屏幕外。改为锚定头像，并限制高度和内部滚动，确保可切换身份。

- 前端 TypeScript 构建通过；当前本地服务健康检查及新资源版本检查通过。
- 29 项相关浏览器回归全部通过，包含教师作业及备课闭环、机构身份与权限隔离、全部角色页面宽度、用户搜索与分页、机构与交易列表及菜单导航。
- 最终构建的 5 项新增浏览器测试通过：六角色共 44 个业务入口在菜单收起时点击进入及返回；课程排序和风险去重；工作流精确筛选；课程包搜索、新建、编辑、失败重试、取消及时间转换；普通机构内容管理员的真实模板保存及角色入口隔离。
- 桌面、手机及深色模式截图和测试输出在 `tmp/role-home-20261022/`。相关新增测试为 `tests/e2e/role-home-navigation.spec.js`。
