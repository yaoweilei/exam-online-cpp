# 角色工作台检查记录（2026-09-12）

## 检查结论

各角色工作台已共用平台管理的顶部栏、分类侧栏、橙色选中态和首页结构。本次检查重点为真实导航、数据状态、身份切换及响应式布局，不代表所有业务提交链路已完整验收。

## 本次修正

| 问题 | 调整 |
| --- | --- |
| 超级管理员无法在统一入口切换全部工作台 | 提供七种工作台，桌面侧栏和窄屏账号菜单均可切换，按账号记住最后身份 |
| Windows 原生身份下拉只触发 `input` 时无法切回平台管理 | 合并 `input` 与 `change`，在下拉关闭后执行一次切换，避免重绘中断原生选择 |
| 身份选择卡与侧栏选中项的橙色边线不在同一垂线上 | 统一身份卡和导航项的水平边界 |
| 窗口高度不足时侧栏还有菜单但滚动位置不可见 | 侧栏中间导航独立滚动并显示纵向滑块，底部账号操作保持固定 |
| 切换控件被异步重绘打断、焦点丢失 | 使用 change 事件并在重绘后恢复身份选择器或账号按钮焦点 |
| 超级管理员教学工作台请求全机构汇总，加载缓慢且范围不清楚 | 增加机构搜索与选择，按当前机构加载；切换时清空旧教学数据并忽略旧机构的迟到结果 |
| 教学数据失败显示零或无记录 | 区分失败与空数据，错误提示带重试，失败指标显示破折号 |
| 正常低风险学员进入续费风险待办 | 只统计 medium/high，并将等级显示为中文 |
| 机构内容角色请求无权访问的教学和成员数据 | 首页读取其课程包内容及状态，不再请求教学工作台、成员、校区或学习组详情 |
| 非平台审计页缺少机构筛选后，剩余网格列仍按七列布局 | 调整缺少机构筛选时的网格定义，避免重置按钮被挤出 |
| 订单标题可点击但点击高度偏小 | 保持无独立详情按钮的简洁形式，标题点击高度至少 32px |
| 内容选择控件尺寸偏小 | 增大复选框及标签点击区域，保留统一橙色强调 |
| 浏览器可能继续加载旧模块和样式 | 更新个人中心及入口资源版本标识 |

## 使用入口与权限边界

- 超级管理员刷新页面、打开个人中心后，在左侧品牌下方的“当前身份”选择工作台。窄屏从右上角账号菜单切换。
- 可切换：超级管理员、学员、老师、教学管理员、机构管理员、机构内容管理员、内容管理员。“平台管理”仅表示管理区域。
- 机构相关工作台顶部可搜索并选择机构。选择列表来自分页摘要，未列出的机构可通过名称或 ID 搜索。
- 切换的是同一登录账号的工作界面，不是登录另一个人的账号，也不是严格的低权限模拟。学员工作台展示当前账号自己的学习记录；机构工作台读取所选机构的数据，服务端仍按真实账号鉴权。
- 普通账号只显示已授予的身份。本地偏好不能增加角色；本次未通过修改超级管理员账号角色数据来实现切换。

## 验证范围

- TypeScript 构建通过。
- 浏览器布局巡检覆盖学员、老师、教学管理员、机构管理员、平台内容管理员、超级管理员的侧栏业务入口，以及学员套餐、优惠邀请、帮助子页；视口宽度为 390、842、1440px。
- 超级管理员七种身份切换、刷新恢复、窄屏菜单与账号角色保持不变均纳入测试。
- 机构内容管理员使用受控接口数据验证课程包指标和请求边界；教学失败重试、风险筛选使用受控数据验证。
- 学习工具弹层、返回入口和键盘焦点另有回归测试。
- 布局检查允许表格、横向导航在自己的容器内滚动，但不允许撑宽整个工作台；复选框按关联标签的实际点击区域检查。

## 尚需独立验收的范围

- 本轮没有实际提交付款、退款、内容发布、权限变更等高影响操作；这些业务仍需专门的端到端验收。
- 超级管理员切换工作台不能代替普通账号的服务端越权测试；机构内容角色的接口隔离测试也不等同于完整后端权限审计。
- 首页与工作台外壳已统一。历史学习工具仍有弹层交互，不能据此声称所有深层业务界面已经完成重新设计。
