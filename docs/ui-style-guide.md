# UI 式样书

## 间距规范

### 页面级块间距

- 页面中相邻的独立内容块、卡片或功能区之间，统一使用 `4px` 间距。
- 本规则适用于首页、答题页、个人中心以及所有角色工作台，并同时适用于桌面端和移动端。
- 页面级布局应优先使用全局变量 `--ui-space-block`，不要在具体页面重复写入 `8px`、`10px`、`12px` 等不同数值。
- 当前标准定义：

  ```css
  :root {
    --ui-space-block: 4px;
  }
  ```

- 推荐写法：

  ```css
  .page-sections {
    display: grid;
    gap: var(--ui-space-block, 4px);
  }
  ```

### 适用边界

- “块间距”指同级页面区域之间的距离，例如搜索卡片与列表卡片、相邻功能卡片、筛选区与结果区之间的距离。
- 按钮内部、文字行距、表格单元格内边距以及图标与文字之间的距离，不属于页面级块间距，可根据控件语义单独设置。
- 如业务页面确需偏离 `4px`，应在样式中注明原因，避免无说明的局部覆盖。

## 管理后台规范

### 信息层级

- 一级页面标题只在工作台顶部栏显示一次，内容卡片不得重复相同标题或使用近义大标题制造第二个页面层级。
- 页面标题统一为 `18px / 24px / 700`；卡片和功能区标题统一为 `14px / 20px / 700`；说明、状态和辅助信息统一为 `12px / 18px`。
- 数据总览中的关键数字可以使用 `22px / 28px / 700`，这是后台唯一允许超过页面标题字号的常规内容。
- 交易后台按职责拆分：“订单与支付”只承载订单、退款、流水和对账记录；“价格与套餐”独立承载商品价格、席位和优惠配置。
- 退款从符合条件的订单详情发起并自动关联订单；配置、创建、退款等不同层级的操作不得混放在同一页头工具栏。

### 表面与间距

- 后台内容区使用 `4px` 外层留白；同级卡片、筛选区、结果区和分页区之间使用 `--ui-space-block`。
- 卡片和独立功能表面统一使用 `--ui-surface-padding: 6px` 与 `--ui-surface-radius: 8px`。
- 移动端只调整列数和排列方向，不得重新放大卡片内边距或区块间距。
- 密集后台页面默认不使用卡片阴影，通过边框、底色和选中态区分层级。

### 控件与操作

- 搜索、筛选、表单输入和对应主操作统一为 `44px` 高、`14px` 字号；输入类控件统一使用 `14px` 圆角。
- 列表行和批量工具栏中的查看、详情、修改、导出等紧凑操作使用 `32px` 高、`12px` 字号；不得为了与表单按钮一致而放大列表行或工具栏。
- 主操作使用深色底白字；次要操作使用白底中性边框；橙色只用于选中态、焦点、强调状态和风险提示。
- 窄屏时允许筛选项换行，表格横向滚动必须限制在表格容器内部，不能撑宽整个工作台。

## 角色工作台规范

### 共用分组列表

- 工作台概况、功能入口、成员角色筛选和成员名单统一采用 iOS 式分组列表，样式集中在 `ios-grouped-workspace.css`，并在各业务样式之后加载。
- 分组标题放在表面外，组内各行共用一个边框和圆角。行高至少 48px，左右留白 14px，内缩细线分隔。页面同级块间距继续使用 `--ui-space-block`。
- 所有角色的浅色工作台采用浅灰页面（`#f2f2f7`）与白色分组（`#fff`），分组使用圆角和底色区分层次，隐藏外描边，保留输入框边框及组内细线（`#e5e5ea`）。页面布局外层透明，不能与白色分组连成整块；学员首页同样沿用此配色。
- 管理工作台暗色模式采用黑色页面（`#000`）、深灰分组（`#1c1c1e`）、浅色正文（`#f5f5f7`）和灰色辅助文字（`#a1a1a8`）。布局外层透明，分组不描外框，组内保留内缩细线；选中项继续使用品牌橙色和勾选标记。成员姓名、标题和展开表单不得沿用浅色主题的固定深色字。
- 名称左对齐，数值、状态和箭头右对齐。导航使用箭头，角色筛选使用勾选标记，并通过 `aria-pressed` 表达当前选择。
- 分组说明标题统一为组外灰色小标题（13px / 20px、500 字重、左右内缩 14px），不得套用页面大标题或粗体卡片标题；例如「机构启用步骤」标题位于白色列表外。
- 工作台界面采用系统无衬线字体栈，苹果设备使用原生系统字体，Windows 使用 Segoe UI 与微软雅黑后备字体；题目日文字体单独保留。顶部栏高 48px，首页与返回按钮为 44px 圆形，返回使用左向折角箭头。有返回路径的子页在顶部栏左侧固定显示返回按钮，各角色总览省略返回按钮。子页主标题滚出视野后，顶部栏显示紧凑标题。
- 展开后的成员权限使用平铺表单行。成员编辑或邀请表单展开时隐藏该名单的悬浮搜索，避免遮挡表单；收起后恢复。
- 学员的自由练习模式和学习档案以分隔行展示。专项模式和学习档案在原地展开，真题模式进入站内独立页，复用工作台的返回按钮和分组列表。统计图、试卷作答、表格和头像预览按各自内容结构展示。

### 手机与窄窗口的共用布局

- 页面两侧留白独立于块间距：手机（容器 ≤600px）16px、平板（601–1200px）24px、更宽工作台 28px。由共用 `--workspace-page-inset` 控制，不能套用 4px 块间距；页面标题与列表外边界对齐，分组小标题与组内文字保留 14px 内缩，悬浮搜索框与所属列表对齐。
- 管理类工作台总览在手机和平板上留出 20px 的底部空间，并为设备底部安全区预留额外距离。
- 各角色工作台页面在滚动到顶端或底端后，继续向边界外滑动时内容轻微移开，手指松开或滚轮停下后恢复原间距。系统启用减少动态效果时，省略回弹动画。
- 平板工作台容器为 601–1200px 时使用 `tablet-workspace.css`；沿用 18/14/12px 字号、6px 表面内边距、8px 圆角及 4px 页面块间距，同时保留可用的多列表单和表格，不直接套用手机单列布局。
- 金额前缀、数值与单位各有独立空间；竖屏时先保证完整金额可见。订单信息格在平板使用两列，日期不得在数字中拆行。
- 平板审计列表直接显示时间、操作者、事件与详情；完整机构信息、摘要和原始字段由详情承载。
- 跟进编辑作为独立任务展示，返回名单保留草稿和筛选；取消编辑明确丢弃当前草稿，编辑期间不展示名单搜索。

- 窄屏以工作台内容容器的实际宽度判断，600px 及以下统一使用手机布局；桌面中的手机预览也执行同一规则。
- 使用 `mobile-workspace.css` 统一窄屏排列，复用本书的字号、表面与间距变量；不得再为某个角色复制一套手机卡片样式。
- 一个业务区只保留一个完整表面。内层成员、权限、课时、报价和进度使用平铺行与内缩细线，不再增加灰底圆角外框。
- 两行列表的行内留白、表单字段间距不属于页面级块间距，可使用 8–12px；同级表面仍使用 `--ui-space-block`。
- 手机课程与课时记录必须直接显示名称、余额、状态和操作，不以横向滑动作为找到主要操作的前提。
- 搜索外置并与列表边界对齐；筛选、排序、顺序和每页数量合并到一个有明确标签的面板，每页默认 10 条；分页区只展示总数和翻页。
- 订单技术字段、表单高级参数和结算中的逐人设置默认收拢。账号页复用工作台的顶部栏与返回路径。

### 统一骨架

- 学员、老师、教学管理员、机构内容管理员、机构管理员和平台内容管理员，均复用超级管理员的工作台外壳、顶部栏、左侧分类导航和卡片规范。
- 页面使用一个主标题。子页标题滚出视野后，顶部栏可显示它的紧凑版本；首页不得再显示重复标题、“可用功能数”或与左侧导航重复的全量入口宫格。
- 管理与教学角色首页使用“四项核心指标 + 待处理 + 快捷操作”结构；学员首页使用“继续上次 + 今日清单 + 按需作业 + 最近完成”。指标和待办必须来自真实业务数据；接口读取期间显示加载状态，不使用演示数字填充。
- 左侧导航按职责分类，而不是简单分成“学习 / 更多”。同一功能只在一个分类中出现，快捷操作只是对高频入口的补充。
- 同一账号拥有多个角色时，每次只激活一个工作台，不得把不同角色的侧栏合并。桌面端在左侧品牌区提供“当前身份”选择，窄屏在账号菜单中提供身份切换；切换后重置页内导航并记住该账号上次使用的身份。

### 角色信息重点

- 超级管理员可切换超级管理员、学员、老师、教学管理员、机构管理员、机构内容管理员、内容管理员七种身份；“平台管理”只作为管理区域名称，不作为身份名称。这不是冒用其他账号或模拟权限降级，服务端仍按真实登录账号鉴权。
- 普通账号只展示已授予的身份；本地保存的身份偏好不能生成新权限。身份被撤销后必须回退到可用工作台。
- 平台总览在「用户与权限」分组中提供「用户管理」「角色权限」「临时授权」三个独立入口。侧栏可直接进入任一页面，各页使用自己的主标题和内容，不显示同组页签。
- 各角色首页共用概况首卡，图标、主标题、简短说明和角色相关的指标或主要入口放在同一张圆角卡片里。机构筛选与数据放在同组，待办和其他功能保留在首卡之后。
- 超级管理员进入机构相关工作台时，显示机构搜索和选择器，按当前机构读取数据，不默认汇总所有机构；切换机构清空旧教学数据，迟到的旧请求不得覆盖新机构结果。
- 教学数据读取失败时显示明确错误与“重试”，对应指标显示破折号，不能把请求失败伪装成零数据。续费风险只统计中、高风险学员，不将正常低风险学员计入待处理。

- 学员：首页使用紧凑清单，只保留一个直接续学的主按钮；已答完未提交显示“检查并提交”，已提交进入最近完成。作业为空时隐藏，逾期或未来 24 小时内截止的作业置顶。每日目标与真实待学题量分别展示，不编造固定学习顺序。主导航为今日学习、我的作业、专项练习、复习资料和学习报告，分为学习安排、复习与分析和账户。错题、收藏和生词统一收入“复习资料”，首页不重复展示全量入口。目标等级筛选推荐练习，不足时显示实际数量；用户主动开始的其他等级试卷仍可继续。
- 老师：学员、学习组、待批改和近期课程；导航分为学员管理、教学任务和教学内容。
- 教学管理员：催交、学员跟进、续费风险和排课；导航分为学员运营和教务支持。
- 机构管理员：成员、付费席位、学习组和课程包；导航分为成员与权限、教学运营和机构管理。
- 机构内容管理员只展示其获授权的课程包内容，不因首页设计而获得学员试卷内容或机构管理权限。
- 平台内容管理员：内容反馈、质检工作流、待发布内容和操作记录；导航分为内容处理和记录。
- 内容反馈与发布工作流使用单层分组列表，数量和说明入口位于组外。默认行只显示摘要、状态和统一折角箭头，展开后展示回复、处理、质检和版本操作；更新状态时保留展开位置与未提交回复。批量选择与行展开分别操作。
- 视觉统一不得改变权限边界。指标卡、待办和快捷操作均必须使用当前角色已授权的入口。

## 账号菜单规范

- 学习页面与所有角色工作台的头像复用同一个账号菜单组件，不再分别维护大面板和工作台菜单。
- 默认显示账号与当前身份；多身份通过折叠列表切换，只列出账号已获授权的角色。单身份隐藏切换项。
- 个人资料、安全、学员套餐权益、帮助及登录操作按职责分组；学习页面额外提供进入当前工作台的入口。
- 问题反馈、客服、协议和隐私等帮助子页使用统一返回按钮，按实际来源逐级返回；从学习页进入时先返回帮助页，再退出工作台。未提交的反馈草稿在当前账号内保留，返回后再次进入不得丢失，也不得展示到其他账号。
- 客服页不重复卡片标题。尚未接入在线会话时，服务说明为静态行，不展示“可用”状态或伪装成聊天入口。账号与支付问题进入专用分类表单，与题目反馈分别保留草稿；账号、支付反馈不要求试卷及题号，不使用演示题目信息代填。
- 打开、关闭菜单不重建页面内容；资料与安全按来源返回，切换账号清理前一账号的菜单状态。
- 菜单贴近头像，宽度不超过 300px，限制可用高度并内部滚动；支持外部点击关闭、Escape 与键盘焦点。

## 个人资料规范

- 所有角色共用基础资料、联系方式、头像、身份与机构四个区域；登录账号与成员编号只读，删除重复的当前昵称和邮箱展示。最近登录归入账号安全。
- 昵称输入与保存按钮等高，未修改时禁用保存；展开其他区域不能丢失昵称草稿，保存成功同步账号显示。
- 联系方式与头像默认折叠，标题左侧、状态摘要和 90° 箭头右侧对齐；展开后使用白底平铺行和内缩细线，不再嵌套装饰卡片。
- 未绑定、已绑定待验证、已验证是三个不同状态；只在绑定或更换表单内说明验证步骤，更换已验证联系人仍必须完成原联系人确认。
- 头像区域展开后，当前头像与全部风格直接展示，不再区分推荐与更多风格，也不增加内层折叠。每种风格只出现一次，候选与选中项保持同尺寸。选择先预览，保存后同步顶部头像；换一批不得自动覆盖当前头像。
- 头像选择区使用紧凑间距和统一缩略图尺寸；手机采用四列，风格名称使用简短中文，避免长英文名称撑高列表。
- 定制头像进入站内独立页，复用工作台标题与返回按钮。窄屏预览、风格与随机按钮放在顶部，宽屏预览放在左侧；编辑选项随页面滚动，底部保留保存和取消。
- 身份与机构展示当前激活身份及实际所属机构，无机构时显示“未关联机构”。学员套餐只保留进入套餐与订单的简洁入口，不重复展开完整订阅信息。

## 账号安全布局

- 所有角色复用紧凑的安全设置列表；手机号摘要使用普通信息行，标题与说明靠左，状态和操作及箭头在右侧对齐，不为操作另起一行。
- 普通账号界面不提供手工选择内部模块、上传/拉取快照或强制覆盖的“多端同步”面板；账号安全保留真实登录会话的“登录设备”管理入口。
- 账号安全只保留主列表；个人资料统一从头像菜单进入。没有绑定操作的 Google 项暂不显示，接入后归入登录方式与绑定。较长账号名称允许自然换行。
- 展开的绑定、设备和注销内容使用白底及内缩细线，避免嵌套装饰卡片；表单控件仍保留至少 44px 高度，验证码、登录方式及注销确认的验证规则不因布局调整而改变。

## 优惠与邀请布局

- 邀请好友、学习金、兑换码、兑换记录作为四个同级表面，不再使用“我的优惠”装饰总框。钱包数据作用域只承担布局与绑定，不显示边框、底色或内边距。
- 推荐链接和复制按钮在邀请区域内直接平铺，不再增加圆角内框；窄屏链接可省略显示，但复制始终使用完整链接。
- 学习金、兑换码和兑换记录默认折叠；标题与简短说明居左，金额或数量及 90° 箭头居右。展开后使用白底和内缩分割线，箭头旋转保持中心位置不变。
- 邀请奖励说明在展开后展示；页内兑换成功后同步更新积分和兑换记录，不另开弹窗。

## 消息中心规范

- 消息中心是账号级公共能力，学员、老师、教学管理员、机构管理员、内容管理员和超级管理员共用同一个入口；切换身份不切换收件箱，也不得展示其他账号的消息。
- 消息按“全部 / 系统与续费 / 教学消息 / 互动消息”分类。系统与续费包括到期、调价、扣款和支付结果；教学消息包括老师催交与批改反馈；互动消息用于评论回复和伙伴消息。
- 消息必须来自真实业务事件。尚未接入消息事件的分类展示明确空状态，不使用演示消息填充。
- 未读状态由服务端保存；支持单条已读、全部已读和刷新。缺少服务端已读能力的业务动态不得伪装为未读消息。
- 套餐、作业等业务页不重复插入消息中心卡片；完整消息列表统一通过工作台导航或账号菜单进入，避免破坏业务页面层级。

## 个人套餐价格展示

- 个人 PRO 分别维护真实的“日常价”和用于报价、下单及续费的“当前售价”。默认日常价为 30 天 `¥15`、90 天 `¥40`、365 天 `¥145`；当前售价为 `¥12.9 / ¥29.9 / ¥99.9`。
- 用户端以当前售价为主价格，同时展示划线日常价；在套餐选择和支付确认处同步展示节省金额。
- 日常价不得低于当前售价。如果两者相同，用户端不展示划线价和节省金额。
- 运营优惠规则若再次命中，应将“当前售价”作为本次折扣基础，不得改变真实支付计算口径。

## 学校 / 教育机构套餐规范

### 计费口径

- 机构套餐按“付费内容席位”计费，不按机构成员总数计费。
- 付费内容席位指可进入试卷、题目、答案或解析等内容区域的账号。学员和内容教师占用席位；同一账号拥有多个内容角色时只计算 1 席。
- 每个机构创建时包含 1 个机构主管理员。机构管理员、教学管理员等纯管理账号可按需增加，不占用付费席位，但不得查看试卷、题目、答案、解析或使用学员作答能力。
- 纯管理账号升级为学员或内容教师时，从角色生效时起占用 1 个付费席位；席位已满时不得授予内容角色。
- 套餐有效期内新增席位与当前机构订阅共用到期日，订单按系统报价结算；不为新增账号单独创建新的订阅周期。

### PRO 年付累进阶梯

- 机构 PRO 支持 30 天月付、90 天季付和 365 天年付。30 天单价为 `¥15 / 席`，90 天单价为 `¥29.9 / 席`；365 天按下方累进阶梯计价。
- 个人和机构 ULTRA 先统一预设为 30 天 `¥39`、90 天 `¥99`、365 天 `¥299`。在 ULTRA 能力边界正式完成前，购买入口、未开放提示和价格维护表格暂时隐藏 ULTRA；保留底层价格配置及已有订单、权益记录，保存其他套餐配置时不得清空 ULTRA 数据。报价和下单接口仍须拒绝创建未开放的 ULTRA 订单。
- 个人套餐时长卡片选中时使用单层橙色边框与浅橙背景，不叠加内阴影、左侧色条或鼠标焦点外框。键盘操作保留清晰的 `focus-visible` 提示；未选中卡片悬停时使用中性边框，避免与选中态混淆。
- 手机套餐购买页通过压缩内部留白、支付方式标签与选择器同行排列，让默认折叠的订单栏可在常用手机高度内完整显示；支付选择器和购买按钮保留至少 44px 高度，不以固定高度或隐藏溢出来强行塞入一屏。展开订单后正常滚动。

- 机构 PRO 年付采用累进计价，只对落入下一档的新增席位使用该档价格，不因跨档而重算前面的席位：

  | 席位区间 | 年单价 |
  | --- | ---: |
  | 第 1～20 席 | ¥99.9 / 席 / 年 |
  | 第 21～200 席 | ¥89.9 / 席 / 年 |
  | 第 201～500 席 | ¥79.9 / 席 / 年 |
  | 第 501 席起 | ¥69.9 / 席 / 年 |

- 示例：购买 21 席的基础金额为 `20 × ¥99.9 + 1 × ¥89.9 = ¥2,087.9`，而不是 21 席全部按 ¥89.9 计算。
- 报价、下单、续费和后台价格预览必须使用同一套累进算法，并展示总价和分档明细，不能只展示最后一档单价。

### 套餐购买与管理边界

- 学校 / 教育机构客户在“套餐与账单”中查看当前套餐、状态、已使用/已购买席位及到期日；这些权益字段均为只读，不能在机构设置中直接修改。
- 拥有机构账单管理权限的客户可选择购买后的总席位、月付、季付或年付周期及支付渠道。系统先返回服务端报价，再创建待支付订单；只有支付回调成功后才更新套餐、到期日和席位。
- “机构设置”只承载校区等机构资料与机构审计，不混入套餐权益修改。
- 超级管理员可在平台机构详情中使用“平台人工调整”，仅用于客服补偿、数据迁移和异常修复，并必须经过二次确认、密码复验和审计记录；正常购买不得使用该入口绕过支付。
- 机构报价和下单接口必须同时校验当前用户对目标机构的 `organization.billing.manage` 权限，不能仅根据前端是否显示按钮判断授权。

### 机构移除与恢复

- 超级管理员在机构详情的「设置」底部移除机构，操作前确认并复验当前密码。移除采用可恢复归档，保留账号、成员关系、教学数据、订单及审计记录。
- 正常机构列表、机构选择器及业务权限不再包含已移除机构；超级管理员通过机构范围筛选「已移除」查看和恢复，恢复后原有成员关系和数据继续可用。
- 存在有效付费套餐、已开启自动续费、待支付订单或未完成退款时，服务端拒绝移除。移除与恢复均写入机构审计，客户端隐藏按钮不能替代服务端授权和状态校验。

### 角色与内容隔离

- 机构主管理员负责成员、角色、套餐、支付和审计；教学管理员负责分组、作业流转、催交和汇总数据。二者默认均为纯管理角色。
- 内容教师可以备课并查看获授权的试卷、答案和解析，因此占用付费内容席位；学员可以练习、提交答案并查看自己的学习结果，同样占用席位。
- 机构角色变更必须写入审计日志。移除最后一名机构管理员、超额授予内容角色或绕过席位上限的操作必须被服务端拒绝。
- 前端隐藏入口只能作为体验优化，服务端仍必须执行角色与席位校验。

### 个人 PRO 邀请奖励

- 邀请奖励作为个人优惠规则独立配置，不参与首购、续费或限时活动的订单减免择优。
- 被邀请用户首次真实支付购买个人 PRO 后，邀请人获得该订单实付金额 `20%` 的学习金，单次最高 `¥20`。
- 学习金使用人民币分单独记账，不得与学习积分混用；奖励仅适用于个人 PRO，不适用于 ULTRA 或学校 / 教育机构订单。
- 同一个被邀请用户只结算一次。后台直接修改套餐、试用、兑换码和赠送订阅均不得触发邀请奖励。
- 订单全额退款或拒付后撤回对应奖励；余额不足以撤回的部分记为学习金欠额，后续到账时应优先冲抵。
